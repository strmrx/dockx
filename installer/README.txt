DockX -- flexible dock layouts for OBS Studio
=============================================

DockX is a native OBS Studio plugin that unlocks flexible dock layouts and a pile
of quality-of-life tools: full-height columns beside stacked panels, saved dock
layouts with hotkeys, source loadouts, source tags with bulk actions, multi-
monitor panels, colors/themes, and more. It lives inside OBS under Tools > DockX.

DockX is FREE. If it saves you time, you can support development from the link on
strmrx.com/dockx. Made by StrmrX -- https://strmrx.com


MANUAL INSTALL (this .zip)
--------------------------
Most people should use the .exe installer instead -- it finds OBS for you and adds
an uninstaller. Use this .zip only if you prefer to install by hand.

  1. Close OBS Studio completely.
  2. Easiest: right-click install.bat and choose "Run as administrator".
     It copies the files into OBS for you.

  OR copy the two files yourself into your OBS install folder
  (usually C:\Program Files\obs-studio):
     - dockx.dll            ->  obs-plugins\64bit\dockx.dll
     - locale\en-US.ini     ->  data\obs-plugins\dockx\locale\en-US.ini

  3. Start OBS and open Tools > DockX.

To remove DockX: run uninstall.bat as administrator (or delete the two files above).


ABOUT THE WINDOWS SECURITY WARNING
----------------------------------
Windows may show a blue "Windows protected your PC" box, and antivirus may pause to
scan the files. This is normal for new software from a small publisher without an
expensive code-signing certificate. It does not mean the files are unsafe.

DockX is open source -- read every line at github.com/strmrx/dockx. If Windows
shows the box for install.bat, click "More info" then "Run anyway".
